# Homebrew Requests and Offers

Homebrew tap for the Requests and Offers Holochain application.

## Installation

```bash
brew tap happenings-community/requests-and-offers
brew install --cask happenings-community/requests-and-offers/requests-and-offers
```

Homebrew 6 and later only load casks from other taps once you trust them. Installing by the full name, as above, trusts this one cask and nothing else in the tap.

If you previously installed Requests and Offers from a DMG, Homebrew will refuse to replace the existing app. Quit the app and add `--force` to the install command.

## Updating

```bash
brew upgrade --cask requests-and-offers
```

## Uninstallation

```bash
brew uninstall --cask requests-and-offers
```
